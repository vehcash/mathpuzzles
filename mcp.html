Teach on the blackboard — for AI assistants

Any AI assistant that speaks MCP can explain maths on the Daily Math Puzzle blackboard. It creates a board, gives you a link, and draws the explanation step by step — equations the board solves, graphs, shaded areas, tangents and geometry you can drag — while you watch it appear live.

MCP server: https://dailymathpuzzle.com/api/mcp.php

Transport: Streamable HTTP. No account, no sign-in, free.

Connect it

  • Claude (claude.ai or the desktop app): in Settings, open Connectors, choose Add custom connector and paste the URL above. Then ask, for example, “Explain completing the square on the Daily Math Puzzle blackboard”.
  • ChatGPT: in Settings, look for Apps & Connectors; with developer mode turned on you can create a connector from the URL above.
  • Claude Code: claude mcp add --transport http dailymathpuzzle https://dailymathpuzzle.com/api/mcp.php
  • Cursor, VS Code and other MCP clients: add a server to your MCP configuration: 
    { "mcpServers": { "dailymathpuzzle": { "url": "https://dailymathpuzzle.com/api/mcp.php" } } }
  • Testing: npx @modelcontextprotocol/inspector, transport “Streamable HTTP”, the URL above.

What the assistant can do

ToolWhat it does
board_guideThe full guide: every drawing command, the maths syntax, layout and a complete example.
create_boardMakes an empty board and returns board_id, edit_key and the view_url to give to the student.
drawAdds commands — step captions, write, equation (solved by the board), system, axes, plot, shade, tangent, point, line, arrow, circle, geometry (named points, polygons, incircle, circumcircle, altitudes, medians…), highlight, wait, clear.
get_boardWhat is on the board, step by step, plus anything the student’s screen could not draw, so the assistant can fix it.

The server also offers the guide as the resource board://guide and a prompt explain_on_board. The guide is public here: board-guide.md.

What a lesson looks like

[
 {"type":"step","title":"The question","text":"Where do $y = x^2$ and $y = x + 2$ meet?"},
 {"type":"axes","id":"A","x_range":[-4,4],"y_range":[-1,7]},
 {"type":"plot","axes":"A","equation":"y = x^2","id":"f","color":"yellow"},
 {"type":"plot","axes":"A","equation":"y = x + 2","color":"blue"},
 {"type":"step","text":"Set the two right-hand sides equal and solve."},
 {"type":"equation","equation":"x^2 - x - 2 = 0","x":0.04,"y":0.15,"solve":true},
 {"type":"step","text":"They meet at $(-1, 1)$ and $(2, 4)$."},
 {"type":"point","axes":"A","x":-1,"y":1,"label":"(-1, 1)","color":"pink"},
 {"type":"point","axes":"A","x":2,"y":4,"label":"(2, 4)","color":"pink"}
]

Positions are fractions of the board (x from left to right, y from top to bottom), so the lesson fits any screen. Captions and written text use LaTeX between $…$; equations and graphs use the board’s calculator syntax (y = sin(x), sqrt(x), x^2).

Watching a lesson

The link opens the blackboard with the lesson’s steps beside it. New steps appear by themselves while the assistant draws. You can go back a step, replay the lesson, copy the link to share it, and draw on the board yourself (your drawings stay on your screen).

Privacy and limits

  • Anyone with a lesson’s link can watch it; only whoever holds its edit_key can change it. Do not put personal information on a board.
  • Boards are deleted 30 days after their last change. Up to 600 commands per board, 80 per draw call.
  • No accounts, no tracking, no advertising. The server stores only the board’s title and commands.
